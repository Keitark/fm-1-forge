# Forge Windows tracker USB update evidence

Refs #3 and #8. Windows preview **3.4.0-alpha.16**, UI resource v8.

An installed tracker can connect through a fixed fresh CDC FWINFO challenge.
The app-only updater validates the generated FWSC/JSON pair, reviews the source
and target builds, requests explicit preparation and administrator access, then
enters UBOOT and captures two matching complete live flash reads. A separately
confirmed application-sector plan governs programming. Per-operation, per-sector
and two complete final readbacks precede a single reset and the exact target
build challenge at the original physical USB location.

The V15 policy preserves boot/configuration/reserved bytes and unused app tail.
It computes the same full candidate independently in JavaScript and the elevated
C# worker. The worker retains immutable source/helper digests, baseline, candidate,
plan and fsynced mutation evidence in administrator-owned storage. Closed IPC
checks owner SID, peer PID, process creation time and job token. Recovery uses
only the original live session and recorded sector scope. Lost sessions, changed
artifacts, uncertain operations and unproven worker shutdown remain blocked.

## Hardware boundary

The production read-only inspector obtained a fresh nonce proof of MOD-EDITOR/1,
build `251763e12335d417fc6b3a370a9600f268c9d26b928be26a74be57d3575eb931`,
with unique physical USB-location binding. Windows supplies PCI and ACPI aliases;
the inspector consistently selects the unique PCI location.

The existing tracker was not stopped, put into UBOOT, erased or reprogrammed by
this feature's development. Native elevated IPC/loader execution, live baseline
capture, no-change return and physical programming through this new route remain
to be qualified. The first reviewed hardware exercise should use the installed
build and its zero-change plan. It cannot qualify physical erase/program.

The prior stock-V15 MIDI installation already has its separate succeeded receipt
and exact tracker boot proof. This host update does not replace that evidence.
